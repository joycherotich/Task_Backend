#  Task App API – Ruby on Rails Backend

This is the **backend API** for the Task Manager application, built with **Ruby on Rails**. It provides a RESTful interface for managing tasks with attributes such as `title`, `description`, and `completed`.

---

##  Ruby & Rails Version

- **Ruby**: 3.2.3  
- **Rails**: 7.0.8.7

---

##  System Dependencies

- MySQL for development
---

## ⚙️ Setup Instructions

bundle install
rails server


### 1. Clone the Repository

git clone https://github.com/joycherotich/Task_Backend.git

cd task_backend
